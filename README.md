## Projects Highlights

### Sustainable Data Center Intelligence Platform (SDCIP)
**Role:** Team Leader | *Graduation Project*
- Architected an AI and Quantum hybrid platform to optimize data center cooling systems, storage hierarchies, and workload scheduling simultaneously.
- Engineered a two-stage thermal forecasting pipeline using **XGBoost** and **LSTM-Attention** with an **MPC** layer to proactively prevent hotspots.
- Developed a **PPO Reinforcement Learning** agent for carbon-aware scheduling and integrated **QAOA / VQE** via Qiskit for combinatorial task allocation.
- Achieved projected simulation results reducing facility PUE to **1.15–1.25**, saving up to **$26.9M** annually, and cutting storage energy by **30%–60%** using a LightGBM classifier.

### Land Cover Classification using Sentinel-2 Satellite Images
*Final Project — Data Scientist Track (DEPI)*
- Built an end-to-end deep learning system for multi-class land cover classification using Sentinel-2 RGB satellite imagery (EuroSAT dataset).
- Fine-tuned a **ResNet-50** architecture, achieving **99.13% accuracy** across visually similar classes (urban, agriculture, forest, water).
- Deployed an interactive **Streamlit** web application for real-time image upload and instant inference, exporting models to **ONNX** and **TensorFlow Lite** for lightweight GIS integration.

### Mobile Market Analytics for Noon
*Final Project — NTI Data Analysis Track*
- Automated data collection by web scraping mobile product listings from Noon using **Python**.
- Cleaned, structured in **MySQL**, analyzed, and built interactive dashboards using **Excel, Power BI, and Tableau** to uncover pricing strategies, 4G/5G adoption, and top brand trends.

### Store Sales & Inventory Dashboard
- Designed a comprehensive **Excel** analytical dashboard tracking sales performance, customer behavior, and inventory turnover through dynamic KPIs and visuals.

### Early Lung Cancer Detection
