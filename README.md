##  Projects Highlights

### Sustainable Data Center Intelligence Platform (SDCIP)
#### Graduation Project
- AI Hybrid System for Energy Optimization in Data Centers
 Architected a unified AI & Quantum platform to optimize data center cooling systems, storage hierarchies, and workload scheduling protocols simultaneously.
 Engineered a two-stage thermal forecasting pipeline using XGBoost and LSTM-Attention with an MPC layer to proactively prevent hotspots and optimize cooling systems.
 Developed a PPO Reinforcement Learning agent for carbon-aware scheduling and integrated QAOA/ VQE via Qiskit to solve combinatorial task allocation.
 Projected high-impact simulation results, reducing facility PUE to 1.15–1.25, saving up to $26.9M annually, and cutting storage energy by 30% to 60% using a LightGBM classifier.

### Land Cover Classification using Sentinel-2 Satellite Images
#### The Final Project in data Scientist training (DEPI)
- Developed an end-to-end AI system for land cover classification using RGB satellite imagery from Sentinel-2 (EuroSAT dataset).
 Trained and optimized a ResNet-50 deep learning model, achieving 99.13% accuracy on the EuroSAT benchmark.
 Addressed challenging visually similar land classes (urban, agriculture, forest, water) with high-precision modeling.
 Built an interactive Streamlit web application enabling real-time image upload and instant land-type prediction.
 Exported the trained model to ONNX and TensorFlow Lite for lightweight, fast, and deployable inference.
 Designed the system for real-time environmental applications and integration with GIS tools (QGIS / ArcGIS).
 Applications include urban planning, environmental monitoring, land-use analysis, and fire detection.
